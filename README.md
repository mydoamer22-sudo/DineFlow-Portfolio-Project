# DineFlow — Restaurant Website Portfolio Project

DineFlow is an original fictional restaurant website concept built with HTML, CSS and vanilla JavaScript. It is intended as a learning and portfolio project.

## Features
- Responsive desktop and mobile layout
- Mobile navigation menu
- Sample menu cards
- Reservation form with browser-side validation
- Accessible labels and status message
- No external libraries or build tools required

## Run locally
1. Download and extract the ZIP file.
2. Open the `DineFlow` folder.
3. Double-click `index.html` to open it in a browser.

For a better development workflow, open the folder in Visual Studio Code and use the Live Server extension if installed.

## Important limitations
This is a front-end demonstration. The reservation form does **not** send, store or confirm real bookings. To use it for a real restaurant, build a secure backend/API, validate input on the server, store reservations in a database, add spam protection, and configure email notifications.

Menu items, prices, address, opening hours and contact details are sample content. Replace them with verified client information before commercial use.

## Suggested improvements
- Add a Laravel or Node.js backend for reservations.
- Store menu items in a database.
- Add tests for form validation and navigation.
- Add real, properly licensed food photography.
- Deploy the site and include a live demo link in your portfolio.
